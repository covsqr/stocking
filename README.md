# Stock RL Trader

실제 상장 종목의 현재가를 기준으로 자동 모의매매와 간단한 Q-learning을 수행하는 로컬 웹 앱입니다. 실제 주문 API는 연결하지 않습니다.

## 실행

```powershell
python run.py
```

브라우저에서 `http://127.0.0.1:8000`으로 접속합니다. 서버가 켜져 있는 동안에는 브라우저를 닫아도 백그라운드 모의매매 루프가 계속 실행됩니다.

## 자동 판단

- 실제 종목 심볼을 최대 8개까지 입력할 수 있습니다.
- 자동 판단은 5분마다 실행합니다.
- 같은 시세를 반복 체결하지 않습니다.
- 실제 비중 조정은 최소 30분 간격으로 제한합니다.
- 자동 후보 교체는 6시간마다 최근 수익률, 중기 수익률, 거래량, 변동성 점수로 수행합니다.
- 무료 Yahoo 시세는 보통 15~20분 지연될 수 있습니다.

## 안전 정책 v3

- 명시적인 `보유` 행동
- 수수료와 슬리피지를 반영한 거래 비용 패널티
- 정책 기준 낙폭 패널티와 `-5%` 손실 제한
- 손실 제한 발동 후 2시간 휴식, 이후 현재 현금 자산을 새 기준점으로 재시작
- 탐색률 감쇠
- 기존 Q-table 아카이브 후 새 정책 학습 시작
- 기존 체결 장부와 전체 누적 수익률 보존

## 화면

- 티커와 종목명을 함께 표시합니다. 예: `SK하이닉스 · 000660.KS`
- 보유 종목별 미실현 손익을 표와 미니 차트로 표시합니다.
- 자동 후보 교체 목록과 다음 교체 예정 시각을 표시합니다.
- UI는 shadcn/ui 계열의 neutral 카드, badge, table 스타일을 기준으로 구성했습니다.

## 주의

이 앱은 실제 주문을 내지 않는 실험용 모의투자 도구입니다. 현재 구현은 단순 Q-learning baseline이며, 실전 투자 조언이나 수익 보장을 제공하지 않습니다.
